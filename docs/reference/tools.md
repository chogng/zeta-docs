# 工具

工具让 Agent 读取环境、修改工作区、运行验证和访问已连接的系统。可用工具取决于产品、当前会话、已启用的扩展能力和权限策略。

## 工具类别

| 类别 | 用途 | 典型结果 |
| --- | --- | --- |
| 文件读取与搜索 | 查找文件、读取内容、定位符号或文本 | 返回工作区中的证据，不修改文件 |
| 文件编辑 | 创建或修改受范围约束的文件 | 产生可检查的工作区改动 |
| 命令执行 | 运行构建、测试、版本控制或开发命令 | 返回标准输出、错误和退出状态 |
| 浏览器交互 | 验证网页行为、填写界面或读取页面状态 | 产生浏览器中的可观察操作 |
| 外部连接 | 调用 MCP 服务器或已连接应用 | 读取或修改外部系统中的资源 |

## Agent 如何选择工具

Agent 会先使用能直接回答问题的窄工具。例如，查找源码时先搜索文件和文本，验证网页交互时使用浏览器，只有需要系统命令时才启动命令执行。

工具名称不等于权限。每次调用仍会根据参数、目标路径、网络访问和可能的副作用单独检查。

## 查看工具活动

工具调用会记录在当前会话中。检查调用时重点查看：

* Agent 传入了什么参数。
* 操作实际影响了哪些文件或外部资源。
* 命令是否正常结束。
* Agent 的结论是否由工具结果支持。

## 扩展工具

使用 [MCP 服务器](/docs/customize/mcp-servers.md) 添加外部服务能力。使用 [Skills](/docs/customize/skills.md) 复用说明、脚本和工作流。两种扩展方式都不能绕过权限与批准。
