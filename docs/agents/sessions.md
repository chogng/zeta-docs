# 会话与任务

会话把你的消息、Agent 的回复、工具活动和任务状态放在同一条连续记录中。一个会话适合处理一个长期目标或一组紧密相关的任务。

## 什么时候继续当前会话

在以下情况继续当前会话：

* 补充刚才任务的验收条件。
* 要求 Agent 修正同一组改动。
* 询问当前进度、失败原因或验证结果。
* 在已有上下文上继续下一个紧密相关的步骤。

当新任务需要完全不同的代码范围、目标或权限边界时，创建新会话。这样可以减少无关上下文，也能让任务记录更容易检查。

## 在任务进行中调整方向

直接发送新消息即可补充或更改要求。明确说明哪些内容仍然有效，哪些内容需要停止。例如：

```text
保留刚才的数据模型改动，停止 UI 修改，先把单元测试补齐。
```

如果 Agent 已经运行会改变外部状态的操作，新的消息不会自动撤销该操作。先查看工具结果，再决定是否需要恢复或执行补偿步骤。

## 检查任务结果

完成后重点检查：

* 修改了哪些文件。
* 运行了哪些验证命令，以及它们是否成功完成。
* 是否还有明确的限制或未完成工作。
* 是否发生了需要你关注的外部状态变化。
