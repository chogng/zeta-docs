# Agent 概览

Zeta Agent 根据你的任务读取工作区、调用工具、修改文件并验证结果。你始终可以查看它正在做什么，并在高风险操作前决定是否继续。

## Agent 如何完成任务

一次任务通常包含以下阶段：

1. Agent 读取指令、工作区状态和你提供的上下文。
2. Agent 搜索相关文件并形成执行路径。
3. Agent 调用读取、编辑、命令或外部工具。
4. 权限系统直接运行安全操作，或请求你的批准。
5. Agent 检查结果并说明完成情况、失败原因和未完成部分。

你可以在任务进行中补充限制或更改方向。新的消息会进入当前会话，而不是创建另一份隐藏任务。

## 写清楚任务

有效的任务说明通常包含三部分：

* **结果**：说明最终需要得到什么。
* **范围**：指出要处理的文件、功能或产品。
* **验收**：说明需要运行哪些测试，或需要满足什么可观察行为。

例如：

```text
修复设置页保存后状态不刷新的问题，只改设置模块，并运行相关的浏览器测试。
```

不需要提前列出实现步骤。Agent 会先检查代码和现有约束，再选择具体改法。

## 上下文来自哪里

Agent 可以使用你直接提供的文字和附件、当前工作区文件、仓库指令、启用的 Skills，以及已连接的 MCP 工具。每种来源仍受工作区信任和权限策略限制。
