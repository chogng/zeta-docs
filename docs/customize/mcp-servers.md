# 连接 MCP 服务器

模型上下文协议（MCP）让 Zeta 使用外部工具、资源和提示模板。连接服务器后，Agent 可以在任务中读取该系统的数据或调用它提供的操作。

## 什么时候使用 MCP

在以下情况连接 MCP 服务器：

* 读取问题跟踪器、知识库或监控系统中的数据。
* 调用团队内部服务提供的受控操作。
* 把同一套外部能力提供给多个 Agent 工作流。

如果需求只是复用一组说明或本地脚本，优先使用 [Skill](/docs/customize/skills.md)。MCP 适合有独立连接、身份验证或服务生命周期的能力。

## 连接后的行为

Zeta 会发现服务器声明的工具和资源，并把可用项加入当前 Agent 环境。配置成功不等于服务器已经可用。连接状态、身份验证和工具诊断分别反映实际运行状态。

工作区可以声明需要的 MCP 服务器，但不能因为配置文件存在就自动获得信任、凭据或更宽的权限。首次使用涉及进程、网络或外部写操作的能力时，Zeta 会按当前策略检查或请求批准。

## 管理访问范围

只连接任务需要的服务器，并检查它会接收哪些输入。MCP 工具可能收到提示内容、选定文件内容或工具参数。服务器返回的数据也应视为外部输入，Agent 不会把它自动当作可信指令。
