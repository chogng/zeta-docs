# Zeta documentation instructions

Before changing documentation, read [`.github/instructions/docs-writing.instructions.md`](.github/instructions/docs-writing.instructions.md). Before changing the site, keep Markdown content, navigation, rendering, and deployment as separate responsibilities.

The `zeta-docs` repository owns public user documentation and its website. The `zeta` source repository owns implementation READMEs, engineering architecture, and source behavior.
